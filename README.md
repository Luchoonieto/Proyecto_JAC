# Proyecto_JAC
Base de datos de Juegos,Canciones y Albumnes

Mi base de datos es para una tienda que vende juegos, canciones y albumnes, tiene como proposito registrar los pedidos de los clientes, siendo este, una solucion al problema que la tienda tiene, ya que busca solucionar registrando los pedidos del cliente junto a su metodo de pago y demas.

# Proyecto_JAC
Base de datos de Juegos,Canciones y Albumnes

Mi base de datos es para una tienda que vende juegos, canciones y albumnes, tiene como proposito registrar los pedidos de los clientes,que producto compro, la cantidad que compro, de que genero es el producto, etc, siendo este, una solucion al problema que la tienda tiene, ya que busca solucionar registrando los pedidos del cliente junto a su metodo de pago y demas.

como el propocito principal de mi base de datos es registrar pedidos, las informaciones que se pueden almacenar y consultar serian las siguientes;

cliente: podemos almacenar y consultar el nombre completo del cliente por separado

producto: al igual que el cliente, podemos saber y guardar, el nombre del producto, tipo (si es cancion, album o juego), precio

pedido: en este, podemos almacenar y consultar quien lo pidio, el precio total y la cantidad de productos que a pedido el cliente
